# WinFlexBison third-party component

The only bundled executable is `win_flex.exe`, from WinFlexBison 2.5.25, which includes Flex 2.6.4. The project uses it to generate `Flex/scanner.cpp` from `Flex/scanner.l`. Bison is not used by this lab.

The Flex license is included in `LICENSE_FLEX.txt`. Upstream source and release:

- https://github.com/lexxmark/winflexbison/tree/v2.5.25
- https://github.com/lexxmark/winflexbison/releases/tag/v2.5.25
